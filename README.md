# AMI Elite Hockey

React + Vite front end with a Supabase (PostgreSQL) backend — generated by ForgeAI.

## Run locally

```bash
npm install
npm run dev
```

The Supabase URL and anon key live in `.env.local` (see `.env.example`). The anon
key is safe in the browser: every table has row-level security enabled.

## Database

- **products** — any visitor can READ; only STAFF can create/update/delete (on staff pages): name, slug, category, price, rating, image_url, description, specs, is_featured
- **orders** — visitors can only SUBMIT (insert) rows — they can NOT read, update or delete any, not even their own; only STAFF read and manage them (on staff pages): customer_name, customer_email, shipping_address, items, total_amount, status
- **gear_reviews** — visitors can only SUBMIT (insert) rows — they can NOT read, update or delete any, not even their own; only STAFF read and manage them (on staff pages): reviewer_name, product_category, rating, headline, comment, is_approved
